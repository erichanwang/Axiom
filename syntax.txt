# Language Syntax and Rules

## Comments
- A '#' begins a comment that runs to the end of the line.

## Variables
- Variables are declared and assigned using the '=' operator.
- The 'let' keyword is not required and is not recognized.
- Variable names should not contain spaces.
- Example:
  x = 10
  message = "Hello, World!"

## Data Types
- The language supports Numbers, Strings, and Arrays (see the Arrays section
  below).
- Types are inferred from the assigned value.
- Numbers are doubles and print with six decimal places.
- String literals must be enclosed in double quotes.
- Printing an array prints "[" + each element (formatted the same way it
  would print on its own) joined by ", " + "]", e.g. [1.000000, 2.000000].

## Arithmetic
- Operators: + - * / %
- Standard precedence: * / % bind tighter than + -, and both bind tighter
  than the comparison operators. Parentheses override precedence.
- Unary minus negates a number: y = -x
- '+' adds when both operands are numbers, and concatenates otherwise:
  prt "count: " + 42     # prints  count: 42.000000
- Division or modulo by zero produces an error value rather than crashing or
  producing NaN. It prints as "ERROR: division by zero" and propagates through
  any further arithmetic.
- Arithmetic on a non-number produces "ERROR: non-numeric operand".
- Example:
  a = 2 + 3 * 4          # 14
  b = (2 + 3) * 4        # 20
  c = 17 % 5             # 2

## Output
- The 'prt' command is used to print values to the console.
- It can print a literal, a variable, or any expression.
- Example:
  prt "This is a message."
  prt x * 2 + 1

## Input
- The 'input' command reads a line from the user into a variable.
- The value is always stored as a string.
- Example:
  prt "What is your name?"
  input user_name
  prt "Hello, " + user_name

## Conditional Logic
- 'if', 'else if', and 'else' statements are supported for conditional execution.
- Conditions must be enclosed in parentheses ().
- Code blocks for each condition must be enclosed in curly braces {}.
- Supported comparison operators: ==, !=, >, <, >=, <=
- A condition is true when it is a true comparison or a non-zero number.
  Strings and empty values are never true.
- Example:
  x = 10
  if (x > 5) {
    prt "x is greater than 5"
  } else if (x == 5) {
    prt "x is 5"
  } else {
    prt "x is less than 5"
  }

## Loops
- 'while' repeats a block for as long as its condition holds.
- 'break' exits the innermost loop; 'continue' skips to its next iteration.
- Example:
  i = 0
  while (i < 5) {
    if (i == 3) {
      break
    }
    prt i
    i = i + 1
  }

## Arrays
- Literal syntax: '[expr, expr, ...]', e.g. a = [1, 2, 3].
- Indexing: 'arr[index]' reads an element. Indexing is a single level only --
  'grid[0][1]' does not parse as chained indexing. To index into a nested
  array, assign the inner array to a temporary first:
    row = grid[1]
    prt row[0]
- Assignment to an index: 'arr[index] = expr'. The target must be a plain
  variable name (not another index expression).
- 'len(arr)' returns the element count as a number. 'len' is a reserved
  builtin name and cannot be declared as a user function.
- Arrays are heap objects with reference semantics, like every other Value
  in this language's runtime: assigning an array to another variable, or
  passing it as a function argument, aliases the same backing storage --
  it does not copy the elements. Mutating an index through one name is
  visible through every other name bound to the same array.
- Index semantics (the interpreter and the codegen agree on this exactly):
  - An index is only valid if it is a Number. A non-numeric index (a string,
    an array, an error, ...) is treated as invalid.
  - A valid index truncates toward zero (7.9 becomes 7, -0.5 becomes 0),
    the same as a C '(long)' cast on the double.
  - Reading ('prt arr[i]', or using it in an expression) with an
    out-of-bounds index (negative after truncation, or >= the array's
    length), a non-numeric index, or indexing something that isn't an
    array, produces the same "ERROR: ..." value that other invalid
    operations in this language produce (e.g. division by zero).
  - Writing ('arr[i] = v') with any of those same invalid conditions is a
    silent no-op: the index expression and the value expression are still
    evaluated (so a function call used as either one still runs and can
    still print), but no store happens and nothing is reported.
- Example:
  a = [10, 20, 30]
  prt a[0]           # 10.000000
  prt len(a)         # 3.000000
  a[1] = 99
  prt a              # [10.000000, 99.000000, 30.000000]
  prt a[10]          # ERROR: index out of bounds
  a[10] = 1          # no-op, a is unchanged

## Functions
- Declared with 'func', a name, a parenthesized parameter list, and a block.
- 'return' returns a value; falling off the end returns an empty value.
- Functions may be called before the line that declares them.
- Recursion is supported: each call gets its own stack frame.
- At most six parameters, matching the six System V register arguments the
  code generator uses.
- Parameters and any variable assigned inside a function body are local to
  that call, and shadow a global of the same name rather than overwriting it.
- Example:
  func factorial(n) {
    if (n <= 1) {
      return 1
    }
    return n * factorial(n - 1)
  }
  prt factorial(6)       # 720.000000

## Unrecognized statements
- Any statement that does not match one of the forms above is silently
  skipped. This preserves the original interpreter's behavior for lines like
  'let x = 10' or 'print x', which are not part of the language.
